# ¿Qué tanto me conoces? 🌙

Un pequeño quiz de amistad para descubrir qué tanto conoces a una persona: sus gustos, personalidad, lado personal y la forma en que vive sus amistades.

La página tiene una estética nocturna con detalles neón y está completamente en español. Incluye preguntas de opción múltiple, puntuación y un resultado final con resumen por secciones.

## Cómo jugar

1. Abre el quiz desde su página web.
2. Lee cada pregunta y elige la opción que creas correcta.
3. Completa las preguntas para ver tu resultado y revisar cómo te fue en cada sección.

No hace falta instalar nada ni crear una cuenta.

## Publicar con GitHub Pages

Este proyecto es una página estática y puede publicarse gratis con GitHub Pages:

1. Sube `index.html` y `README.md` a la raíz de un repositorio.
2. Entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/ (root)`, y guarda los cambios.
5. Cuando termine la publicación, GitHub mostrará el enlace del sitio en esa sección.

## Privacidad

El quiz funciona directamente en el navegador. No requiere una cuenta y, en su versión actual, no guarda las respuestas ni las envía a un servidor.
